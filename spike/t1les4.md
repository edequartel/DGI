# LEGO SPIKE Prime – Kleurenmuur Code
## Project – 3 lesuren

Leerlingen gebruiken een kleuren­sensor op de verrijdbare basisrobot.  
Gekleurde LEGO blokken vormen samen een “code-muur”.  
De robot leest de kleuren en voert opdrachten uit.

Voorbeeld:

- rood = stoppen
- groen = vooruit
- blauw = draaien
- geel = geluid

---

# Les 1 – Kennismaken met de kleursensor

## Leerdoelen

- Werken met de kleursensor
- Kleuren herkennen
- Robot testen

## Activiteiten

### Introductie

Bespreken:

- Hoe herkennen robots kleuren?
- Waar worden kleurensensoren gebruikt?

---

### Sensor testen

Leerlingen testen de kleursensor met:

- rode blokken
- blauwe blokken
- groene blokken
- gele blokken

---

### Programmeren

Leerlingen maken een programma:

- als rood → stop
- als groen → vooruit
- als blauw → draai

---

## Afsluiting

Robot laat kleuren herkennen.

---

# Les 2 – Kleurenmuur als code

## Leerdoelen

- Kleuren gebruiken als opdrachten
- Programmeren met meerdere acties

## Activiteiten

### Kleurenmuur bouwen

Leerlingen bouwen een muur van gekleurde LEGO blokken.

Bijvoorbeeld:

| Kleur | Actie |
|---|---|
| Groen | Vooruit |
| Blauw | Links draaien |
| Rood | Stoppen |
| Geel | Geluid |

---

### Programmeren

Robot leest kleuren één voor één.

De robot voert daarna de juiste actie uit.

---

### Testen

Leerlingen testen verschillende kleurcodes.

---

## Afsluiting

Bespreken:

- Welke code werkte goed?
- Welke kleur was moeilijk?

---

# Les 3 – Eigen kleurencode maken

## Leerdoelen

- Eigen code ontwerpen
- Samenwerken
- Probleem oplossen

## Activiteiten

### Eigen opdracht

Leerlingen maken een eigen kleurencode.

Bijvoorbeeld:

- een parcours;
- een geheime code;
- een dansrobot;
- een muziekrobot.

---

### Challenge

Andere groepjes moeten raden wat de code doet.

---

### Presenteren

Leerlingen demonstreren hun robot.

---

## Afsluiting

Bespreken:

- Wat heb je geleerd?
- Hoe werkte de samenwerking?
