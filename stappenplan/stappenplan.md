# 🧠 Werkblad: Programmeer een route naar het ICT-lokaal

## Situatie
Je staat buiten voor de school.  
Je doel: **op je stoel in het ICT-lokaal gaan zitten.**

Je gaat dit simuleren alsof je een **robot** bent die alleen simpele opdrachten begrijpt.

---

## 🔧 Beschikbare commando’s

| Commando        | Betekenis |
|-----------------|------------|
| `draai_links`   | Draai 90 graden naar links |
| `draai_rechts`  | Draai 90 graden naar rechts |
| `loop_vooruit`  | Zet één stap vooruit |
| `open_deur`     | Open de deur (alleen als hij dicht is) |
| `sluit_deur`    | Sluit de deur |
| `ga_zitten`     | Ga op een stoel zitten |
| `wacht`         | Wacht op iets of iemand (bijv. als iemand voor je loopt) |

---

## ✍️ Opdracht 1: Bedenk de route

Teken of beschrijf kort waar je staat, waar de deur is en hoe je bij het ICT-lokaal komt.  
Gebruik pijlen of woorden.  

**Voorbeeld:**

```
[Schoolplein] → [Hoofdingang] → [Gang] → [Trap] → [ICT-lokaal]
```

---

## 💻 Opdracht 2: Schrijf jouw stappenplan in code

Gebruik de commando’s hierboven om jouw route te programmeren.  
Schrijf de stappen één voor één onder elkaar.

**Voorbeeld:**

```

loop_vooruit
open_deur
loop_vooruit
draai_links
loop_vooruit
draai_rechts
open_deur
loop_vooruit
ga_zitten
```


---

## 🚀 Opdracht 3: Test met een klasgenoot

1. Lees jouw code voor aan een klasgenoot.  
2. De klasgenoot speelt de **robot** en voert de stappen uit.  
3. Controleer of de “robot” goed op de stoel in het ICT-lokaal terechtkomt.  
4. Verbeter eventueel jouw stappenplan.
