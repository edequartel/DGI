# 📘 Les 1 – HTML Basis  

HTML is de **taal van websites**.  
Je schrijft **tekst** met **tags**.  
Een *tag* is een woord tussen `<` en `>`.

Voorbeeld:  
`<p>` begint een paragraaf.  
`</p>` sluit de paragraaf.

---

## ✨ Belangrijk
- Een tag begint met `<tag>`  
- Een tag eindigt met `</tag>`  
- Wat zichtbaar is op de website staat in `<body> ... </body>`

---

# 🧪 Voorbeeldcode – jouw eerste webpagina

```html
<!DOCTYPE html>
<html lang="nl">
<head>
  <meta charset="UTF-8">
  <title>Mijn eerste webpagina</title>
</head>

<body>

  <h1>Welkom op mijn pagina</h1>

  <p>
    Dit is mijn eerste HTML-pagina.
    HTML is een taal voor websites.
  </p>

  <h2>Wat ik leuk vind</h2>

  <p>Ik leer programmeren met HTML.</p>

  <p>Ik kan tekst schrijven, titels maken en links toevoegen.</p>

  <a href="https://www.example.com">Klik hier voor een voorbeeldwebsite</a>

</body>
</html>



⸻

🎧 Uitleg
	•	<!DOCTYPE html> → Dit is een HTML5 document
	•	<html> → De hele pagina
	•	<head> → Instellingen, titel
	•	<body> → Alles wat zichtbaar is
	•	<h1> → Hoofdtitel
	•	<p> → Paragraaf
	•	<a href=""> → Link

⸻

🏁 Opdracht

Maak zelf een pagina met:
	•	één <h1> titel
	•	één <h2> ondertitel
	•	twee paragrafen
	•	één link
	
```
